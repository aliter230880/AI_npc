# Requirements — AI Character Platform

## Видение

Платформа, на которой пользователь создаёт AI-персонажей с собственным характером, голосом, базой знаний и долговременной памятью, и общается с ними текстом или голосом через веб-интерфейс или встроенный SDK (Web/Unity).

## Целевая аудитория

- **B2C-веб**: люди 18+, общение с персонажами для развлечения, ролёвок, обучения
- **B2B геймдев**: студии и инди, встраивающие живых NPC в Unity/Unreal проекты через SDK

## Принципиальные решения

| Тема | Решение |
|---|---|
| Языки на запуск | EN, далее RU/ES, потом ZH |
| LLM | OpenRouter (uncensored Llama/Mistral/Hermes на старте), без OpenAI/Anthropic |
| TTS | Silero локально, далее ElevenLabs |
| STT | whisper.cpp локально |
| Vector DB | Qdrant (Docker) |
| Контент | NSFW разрешён, гейт 18+, фильтр только на нелегальное (CSAM, экстремизм) |
| Платежи | ЮKassa + crypto USDT, без Stripe |
| Хостинг | свой VPS (aeza/Hetzner), Cloudflare CDN |

## Функциональные требования

### FR-1: Аутентификация
- Регистрация по email+пароль с подтверждением 18+
- Логин с выдачей JWT (access + refresh)
- Refresh-токен в httpOnly cookie
- Восстановление пароля по email

### FR-2: Управление персонажами
- CRUD-операции владельцем
- Поля: name, description, avatar_url, system_prompt, backstory, personality_traits, voice_id, language, model, temperature, is_public, tags, nsfw_flag
- Публичные персонажи доступны всем для общения, не для редактирования
- Лимиты по тарифу: количество персонажей у юзера

### FR-3: Текстовый чат
- Создание сессии чата с конкретным персонажем
- Отправка сообщения, получение ответа стримом (SSE)
- История диалога сохраняется и загружается при возврате
- Ограничение контекстного окна — последние N сообщений + summary более старых

### FR-4: Голосовой чат (этап 2+)
- WebSocket /voice/{session_id}: аудио-стрим в обе стороны
- VAD на фронтенде, STT на бэке
- LLM streaming → TTS streaming для минимальной latency

### FR-5: Long-term memory (этап 3+)
- Автоматическая суммаризация старых сообщений
- Сохранение в Qdrant per (character_id, user_id)
- Retrieval релевантных воспоминаний при новом сообщении

### FR-6: Knowledge Base (этап 3+)
- Загрузка PDF/MD/TXT/DOCX к персонажу
- Чанкинг и эмбеддинги в Qdrant
- RAG в чате

### FR-7: API для разработчиков (этап 4+)
- API-ключи `cp_live_xxx` / `cp_test_xxx`
- REST + WebSocket
- Rate limiting
- Учёт токенов и стоимости

### FR-8: SDK (этап 5+)
- JavaScript npm-пакет + embed-виджет
- Unity UPM-пакет

### FR-9: Тарифы и биллинг (этап 4+)
- Free / Hobby / Pro / Custom
- Учёт расхода
- ЮKassa и crypto

## Нефункциональные требования

- **Latency text**: первый токен < 1.5 сек
- **Latency voice**: ответное аудио стартует < 2 сек после конца фразы
- **Uptime**: 99% (приемлемо для старта)
- **Безопасность**: bcrypt для паролей, HTTPS обязательно в проде, JWT с коротким TTL access (15 мин), refresh 30 дней
- **Приватность**: юзер может удалить свои данные и память персонажей о себе
- **Совместимость браузера**: Chrome/Firefox/Safari последние 2 версии, Edge

## Out of scope (на старте)

- Мобильные приложения (iOS/Android) — только веб
- Voice cloning — этап 9
- Multi-character сцены — этап 9
- Image generation в чате — этап 9
- Unreal SDK — этап 9
- Полноценная модерация UGC — только базовый блок-лист на старте
